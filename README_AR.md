# Flutter Freelance Mastery — الإصدار التفاعلي (32 أسبوعًا)

الخطة: **32 أسبوعًا × 7 أيام × ساعتين = 224 يومًا / 448 ساعة**. لا تعتمد على الفيديوهات. تحتوي على شرح نصي وتمرين ومعيار مراجعة وبرومبت لمدرب ChatGPT لكل يوم، بالإضافة لبحث الدروس، وتسجيل الملاحظات والوقت، ومتابعة التقدم والعملاء، والنسخ الاحتياطي، ودليل PDF مكمل.

## تثبيت التطبيق على iPhone

1. بعد فك ضغط ZIP، ارفع **محتويات المجلد** إلى مستودع GitHub جديد (ملفات `index.html` و`sw.js` و`manifest.webmanifest` ومجلد `icons`).
2. في المستودع: `Settings → Pages → Build and deployment → Deploy from a branch`، وحدد `main` ثم `/(root)` واضغط Save.
3. استخدم **الرابط الفعلي** الذي سيعرضه GitHub Pages بعد النشر. افتحه في Safari على iPhone.
4. اضغط `Share → Add to Home Screen → Add`. وإذا ظهر `Open as Web App` ففعّله.
5. افتح التطبيق أول مرة وأنت متصل بالإنترنت ليحمّل محتواه للتشغيل لاحقًا دون اتصال.

**تنبيه:** الرابط يكون خاصًا بمستودعك، لذلك لا يوجد داخل الحزمة رابط GitHub Pages جاهز قبل أن تنشرها بنفسك. لو المستودع عام فالمحتوى ظاهر للآخرين، أما التقدم والملاحظات فيُحفظان محليًا في متصفحك ولا يُرفعان بواسطة التطبيق.

## تشغيله على Windows 10/11

- افتح `index.html` من المجلد مباشرة على Edge/Chrome لتشغيل المحتوى والتفاعلات. **التثبيت كـWeb App والعمل دون اتصال بعد التحميل** أفضل من الرابط المنشور على GitHub Pages.
- بعد نشره: افتح الرابط في Edge أو Chrome؛ إذا ظهر خيار `Install app` من المتصفح فاختَره، وسيظهر تطبيق مستقل.

## الاستخدام اليومي

1. اختر رقم الأسبوع أو ابحث عن الموضوع. افتح **«اشرح درس اليوم»**.
2. اقرأ الشرح والمثال والـLab ومعايير الإتقان؛ كلها تعمل بعد تخزين التطبيق دون إنترنت.
3. اضغط **«انسخ برومبت اليوم»** والصقه في ChatGPT ليكون مدربك التفاعلي، يسأل ويصحح كودك وينتظر محاولتك. **ChatGPT يحتاج إنترنت**.
4. سجّل ملاحظاتك ودقائق مذاكرتك، وعند إنجاز التمرين والاختبار فقط علّم اليوم كمكتمل.
5. استخدم **«تنزيل نسخة احتياطية JSON»** دوريًا. انقل الملف للكمبيوتر أو الآيفون، ثم اختر **«استيراد نسخة احتياطية»** لمتابعة التقدم.
6. للتصفح بدون التطبيق استخدم `Flutter_32_Weeks_Study_Guide.pdf` (33 صفحة)؛ وهو ملخص لكل يوم وليس بديلًا عن المصادر التفصيلية.

## متى تستطيع البيع أثناء التعلم؟

المواعيد التالية **مؤشرات مشروطة وليست ضمانًا للعمل**:

- **الأسبوع 6–8:** تنفيذ واجهة أو إصلاح تنسيق إذا استطعت إنتاج تصميم مشابه بنفسك واختباره على أكثر من شاشة.
- **الأسبوع 10–12:** ربط REST API أو Firebase Auth مع حالات الخطأ واختبار الصلاحيات.
- **الأسبوع 15–20:** تطوير ميزة محددة أو MVP محدود مع README وTests وتسليم واضح.
- **الأسبوع 26–29:** Bug Fixing وصيانة ونشر بعد تدريب فعلي واختبار على المنصات المطلوبة.

لا تقبل نطاقًا أكبر من قدرتك: عند غموض المتطلبات اطلب توضيحًا قبل التسعير. وثق الحسابات الخارجية وتكاليف التشغيل والملكية والخصوصية. نشر iOS تقليديًا يتطلب macOS/Xcode وحساب Apple مناسب، فلا تعد العميل بنشر iOS عبر Windows وحده.

## ما يجب معرفته عن حفظ التقدم

- التخزين تلقائي **محلي على الجهاز والتطبيق** (`localStorage`)، بدون حساب أو خادم.
- **لا توجد مزامنة تلقائية** بين Safari، وتطبيق Home Screen، والويندوز. حتى على نفس iPhone قد يكون لكل سياق مساحة تخزين مختلفة. استخدم Export/Import.
- إذا حذفت بيانات الموقع أو التطبيق قد تفقد تقدمك؛ احتفظ بنسخ احتياطية.
- يمكن استيراد JSON قديم من خطة الـ24 أسبوعًا. أول 168 يومًا ما زالت بنفس الترتيب لتسهيل الانتقال.
- ملحوظة: أدوات المتصفح واختبارات الموقع تحققت في محاكاة مقاس هاتف وكمبيوتر؛ لم يجرِ اختبار عملي على جهاز iPhone فعلي ولا رفع مستودع نيابة عنك.

## طريقة تحديث النسخة بعد النشر

ارفع الملفات الجديدة إلى نفس المستودع وانتظر GitHub Pages. `sw.js` يستخدم Cache بنسخة `flutter-mastery-32w-v3`. عند تغيير الملفات لاحقًا، زد رقم نسخة CACHE لضمان ظهور التغييرات للمستخدمين. احفظ Backup قبل التحديثات الكبرى.

## محتويات الحزمة

- `index.html`: التطبيق التفاعلي الكامل.
- `manifest.webmanifest` + `sw.js` + `icons/`: التثبيت والتخزين Offline.
- `Flutter_32_Weeks_Study_Guide.pdf`: دليل يومي قابل للطباعة.
- `PLAN_DATA.json`: جدول جميع الأسابيع والأيام للرجوع أو التطوير.
- `MARKET_SKILLS.md`: أمثلة طلبات عمل حقيقية دعمت ترتيب المهارات.
- `README_AR.md`: الدليل الحالي.

## 6) ترتيب المقرر والسوق
تأتي الآن مرحلة تحويل Figma وRTL في الأسبوع التاسع، ثم APIs وState Management وFirebase، ثم تطبيقات الحجز والمتجر، وبعدهما Debugging وMaps وPayments والنشر. تبدأ مهام فهم السوق الخفيفة من البداية، ويتصاعد التواصل مع العملاء عند وجود أعمال تُثبت القدرة. كل يوم سابع يحتوي على نشاط سوق عملي.

## 7) طريقة الاستعمال بمسؤولية
استخدم «اشرح درس اليوم» كملخص مُوجّه، والمراجع المكتوبة للتعمق، وبرومبت اليوم لطلب تدريب خطوة بخطوة من ChatGPT. الشروحات ليست كتابًا أصليًا مطبوعًا شاملًا يغني عن التوثيق الرسمي. لا تعتمد على الكود التجريبي وحده للمدفوعات الحقيقية أو بيانات العملاء الحساسة.
